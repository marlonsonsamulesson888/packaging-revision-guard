# 匿名流程情景检查

这是编写者依据规则进行的桌面检查，不是独立新会话或视觉工具实测。

1. 同一文件路径被当作新旧稿：脚本实际输出 same_file=true。流程应提示重复选样，不能宣布客户两版本一致。
2. 不同文件路径但字节一致：单元测试通过。结论只能覆盖收到的两个文件，不推断客户端曾存在的原始版本。
3. 文件字节不同但尚未渲染：单元测试验证不同散列。没有版面检查证据时只能说字节不同，不猜文字或布局变化。
4. 两张后补截图肉眼相似、二维码低清：按照模块需新建样本编号，旧 PDF 结论不转移；二维码必须标无法确认，不自行打开目标 URL。
5. 仅检查第一页：报告覆盖范围写第一页，其余页面未检查，不得写全部一致。
6. PDF 渲染页框尺寸不同：先报告尺寸/页框差异，不能拉伸后宣布一致。

CLI 额外实测：同路径正常记录；不存在路径退出 2；输出不含文件路径。只读脚本不解析 PDF、图像或二维码，未对这些格式做视觉实测。
