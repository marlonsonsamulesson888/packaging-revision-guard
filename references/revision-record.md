# 改稿记录（复制到项目填写）

- 基线文件、画板/页/面位：
- 基线和工作副本版本；保存状态；校验记录：
- 用户要求原文：
- 允许改动：对象 / 属性 / 原值 / 目标值 / 单位与参照
- 保护项：对象 / 不变属性 / 核验方法
- 缺项或冲突：
- 核验：目标改动、保护区、批注清除、文字/条码、源稿与导出对应
- 核验范围与证据：文件级 / 对象级 / 视觉级，逐项写已查或未查
- 结果：通过 / 需修正 / 未验证；剩余风险：

## 合成示例
只将正面 Logo 向右移动 5 mm，尺寸、颜色、角度不变。背景、产品图、标题、条码和刀模都保护。
若原稿只有未标尺截图：可先提取位置意图，不能宣称已完成精确 5 mm 改稿；取得尺寸依据再操作。
如果文件散列发生变化：只说明文件字节变化，仍需检查 Logo 的坐标及其他对象；若前后散列相同，也不能推出历史上从未改动。
